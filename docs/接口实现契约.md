# 接口实现契约
所有接口前缀 `/api`，成功 `{data,message}`，分页 `{records,total}`，错误 `{message}`。JSON camelCase，金额数字，时间ISO。Session Cookie；先 GET /auth/csrf 获得 `{token,headerName:"X-CSRF-TOKEN"}`，所有修改请求携带此头。

身份：GET /auth/captcha 返回 `{image,captchaId}`（图片data URL，验证码存在Session）；POST /auth/registrations 与 POST /auth/login 均用 `{username,password,captcha}`。注册另有 role(USER/MERCHANT)、name、phone、email、city、gender、bankAccount、shopName、licenseFileId、identityFileId。登录返回安全用户字段。GET /auth/me、GET/PATCH /users/me、POST /auth/logout。

商品：GET /categories 数组；GET /products?keyword=&sort=priceAsc|priceDesc|sales|positive&page=1&size=12；GET /products/{id}。字段 id,shopId,shopName,sellerName,name,categoryId,originalPrice,discount,price,description,size,instructions,negotiable,conditionText,stock,status,imageUrls,soldCount,positiveRate。GET /shops/{id}；GET /shops/{id}/products。GET/POST /seller/products；PATCH /seller/products/{id}；POST /seller/products/{id}/submissions 和 /off-shelf。发布使用上述商品字段及 imageIds 数组。

购物车 GET/POST /cart/items，POST `{productId,quantity}`；PATCH /cart/items/{id} `{quantity}`；DELETE 同址。

POST /checkouts `{requestKey,points,items:[{productId,quantity}],appointments:[{shopId,appointmentTime,appointmentPlace}]}`，返回批次 `{id,orders,totalAmount,paidAmount,usedPoints}`。

GET /orders 和 /seller/orders 分页；GET /orders/{id} 含 items。POST /orders/{id}/cancellations `{reason}`；POST /orders/{id}/confirmations；卖家 POST /seller/orders/{id}/deliveries 和 /cancellations；PATCH /seller/orders/{id}/appointment `{appointmentTime,appointmentPlace}`。

POST /order-items/{id}/returns `{reason}`；GET /returns 和 /seller/returns；POST /seller/returns/{id}/reviews `{approved,reason}`；POST /seller/returns/{id}/receipts。POST /order-items/{id}/reviews `{productStars,serviceStars,content}`；POST /seller/order-items/{id}/reviews `{buyerStars,content}`；GET /products/{id}/reviews，GET /users/{id}/reputation。

GET /wallet 返回 available,frozen；GET /wallet/entries 分页。GET /points 返回 available,frozen；GET /points/entries 分页。

POST /files multipart file,purpose(PRODUCT,LICENSE,IDENTITY)，返回 id,url；GET /files/{id} 图片（证件仅本人管理员）。注册前上传亦可，使用Session绑定归属。

管理：GET /admin/registrations；POST /admin/registrations/{id}/reviews `{approved,reason}`；GET /admin/products；POST /admin/products/{id}/reviews 同参数。GET /admin/users；PATCH /admin/users/{id} 用户资料；DELETE 同址；POST /admin/users/{id}/recharges `{amount,requestKey}`。GET /admin/shops、/admin/merchants、/admin/fees；PATCH /admin/shops/{id}/level `{mode:"AUTO"|"MANUAL",level}`；POST /admin/shops/{id}/closures、/reopenings。GET/POST /admin/blacklists 和 /seller/blacklists，POST `{buyerId,reason}`；DELETE 相应 /{id}。

状态：用户 PENDING/APPROVED/REJECTED；商品 PENDING/ON_SHELF/OFF_SHELF/REJECTED；订单 PAID/DELIVERED/CONFIRMED/CANCELLED；售后 PENDING/REJECTED/TRANSIT/RETURNED。

补充：商品响应含 imageIds（编辑沿用本人图片）；订单列表和详情均包含完整 items，并返回买家名、卖家名、店铺名下单快照。GET /shops/{id} 返回 soldCount、servicePositiveRate（无评价null）、reviewCount、sellerName 和最近10条 reviews，评价含 authorName、productStars、serviceStars、content。所有 records/total 列表支持page/size，默认1/12，size最大100。购物车为数组，每行含嵌套product。
