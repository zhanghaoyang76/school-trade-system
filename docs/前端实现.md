# 前端实现

## 范围与当前状态

正式Vue应用已实现，未使用设计HTML冒充业务系统。最终7项前端检查、生产构建、3项浏览器回归及真实MySQL交易与页面取消联调通过，详细结果见《联调与测试》。后文保留初次构建检查经过。

## 文件职责

| 文件或目录 | 作用 |
|---|---|
| src/main.js | 安装路由与Element Plus，启用简体中文本地化 |
| src/App.vue | 统一顶栏、搜索、按角色显示菜单与登录状态 |
| src/router.js | 页面按需加载、登录及角色导航守卫，服务端仍为最终权限边界 |
| src/api.js | 会话请求、CSRF令牌、HTTP错误反馈及返回数据解包 |
| src/state.js | 当前登录用户和会话刷新，退出清理令牌 |
| src/styles.css | 已选页面规则、组件样式、桌面与手机适配 |
| src/components | 工作区侧栏、上传与黑名单等重复组件 |
| src/pages | 商品、注册登录、购物车、结账、订单、退货、钱包积分、资料、卖家及后台页面 |
| tests/api.test.js | 请求层真实Response对象及错误处理断言 |

## 数据流

页面事件收集表单参数 → api.js按路径调用/api并携带Session → 修改请求取得并携带CSRF令牌 → 后端验证并执行业务 → 页面展示真实响应或服务端错误。Vite把/api代理至8080，避免开发中直接跨源丢失Cookie。

关键业务数据从接口获取，不在页面硬编码商品销量或余额。结账携带同一请求号重试，避免网络失败重复扣款；服务器必须同时实现幂等。下单及退款金额以后端结果为准。

## 页面与交互

正式界面延续白底、深灰文字、少量红色操作、商品大图和正常字号。使用真实上传图片，空数据展示空态。表单、资金与管理操作提供操作中及失败状态，不将前端隐藏按钮当成权限控制。
