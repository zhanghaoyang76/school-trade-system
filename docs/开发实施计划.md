# 开发实施计划

> 执行方式：当前会话依照writing-plans和subagent-driven-development逐项实施、需求审查和代码审查；不在阶段间反复询问是否继续。用户已确认完整设计，新的业务歧义再询问。

**目标：** 实现可运行且覆盖课程全部必做功能、关店和拉黑的校园二手交易平台，并提供真实验证及模块讲解。

**架构：** Vue前端、Spring Boot分层后端及MySQL，文件本地存储。共享后端业务服务确保人工接口、定时任务使用同一事务和状态转换。

**技术：** Java21、Spring Boot3.5、MyBatis Plus/MyBatis XML、Vue3/Vite/Element Plus、MySQL8、Session、Spring定时任务和AOP。

## 阶段一：项目初始化及数据契约

- [ ] 初始化开发分支`development`，将已确认设计提交本地Git；不创建未知GitHub仓库。
- [ ] 创建`backend/pom.xml`、应用配置及`database/schema.sql`，按《数据库设计》定义17张表及必要约束。
- [ ] 创建`docs/接口实现契约.md`，明确字段、状态、金额、权限和成功失败响应。
- [ ] 为后端提供JUnit与H2的测试配置；H2仅用于自动化测试，正式应用仍使用MySQL。
- [ ] 编写真实下单回滚、确认、退款、库存及权限测试，先执行并确认因功能缺失失败，再实现对应模块。

配置核心示例：

```properties
spring.datasource.url=${DB_URL:jdbc:mysql://localhost:3306/2024011490?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai}
spring.datasource.username=${DB_USER:root}
spring.datasource.password=${DB_PASSWORD:}
```

验证命令：`mvn -f backend/pom.xml test`。首次新业务测试预期因功能缺失失败；实现后预期全部通过。禁止将未执行的结果写为通过。

## 阶段二：后端业务

- [ ] 文件范围：`backend/src/main/java/campus/market/`、`backend/src/main/resources/mapper/`、对应`backend/src/test/`。
- [ ] 登录与注册审核、验证码、私有证件上传及公开商品图，使用Controller/Service/Mapper分层和DTO。
- [ ] 商品多图、分类、审核、发布下架、搜索排序、店铺；XML真实执行动态查询和关联统计。
- [ ] 跨店购物车、整次结账事务、明细快照、交付、取消、并发库存和幂等。
- [ ] 充值与流水、托管结算、手续费、冻结与释放、积分、退货时限及交回、重复任务防重。
- [ ] 双向评价及好评率、自动和手动等级、关店、恢复及两级黑名单；管理员用户维护。
- [ ] 核心资金示例测试：商品100元用100积分后钱包付款99元，个人卖家收99元；收货后收入冻结；退货审核通过退99元和100积分、取消99奖励积分，交回后才恢复库存。
- [ ] 负例测试：购物车一个商品无库存时其他商品也不扣库存、不扣款；未登录、跨卖家操作及拉黑购买失败。
- [ ] 检查17表及全部接口没有空壳，实现后执行`mvn -f backend/pom.xml test`和`mvn -f backend/pom.xml package`。
- [ ] 需求符合性审查通过后再做代码质量审查；修正发现的问题并重跑对应验证。

## 阶段三：前端业务

- [ ] 文件范围：`frontend/package.json`、`frontend/src/`、`frontend/vite.config.js`。
- [ ] 依《页面设计规范》实现Airbnb参考方向，使用路由和Element Plus表单表格；正式页面使用真实API，不用草图数据冒充业务。
- [ ] 实现交易、卖家及管理全部页面；共享API模块带Session和CSRF，所有字段验证错误可见。
- [ ] 页面覆盖：注册登录、商品与店铺、详情、多图上传、购物车结账、订单、售后、钱包积分、评价信用；卖家商品及交易售后、黑名单；后台审核、用户、充值、等级费率、关店、平台黑名单。
- [ ] 验证命令：`npm.cmd --prefix frontend install`、`npm.cmd --prefix frontend run build`。
- [ ] 浏览器运行验证登录与主交易链路，至少1440桌面及390手机截图；检查前后端字段和权限一致。
