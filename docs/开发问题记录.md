# 开发问题记录

以下均为实际遇到的问题，不填写虚构工时。

| 问题 | 实际原因或证据 | 处理与验证 |
|---|---|---|
| 旧Word编号读取失败 | Word COM返回E_ACCESSDENIED，粗提取不保留自动编号 | 保留原件，不猜测3.3标题；项目开发继续 |
| 本地设计预览打不开 | 受限环境套接字拒绝，允许环境请求端口仍超时 | 改提供自包含离线HTML及直接截图 |
| MySQL连接拒绝 | MySQL80停止，3306未监听；启动服务权限不足 | 用户手动启动后连接成功，创建本人学号库 |
| Maven依赖缓慢 | 依赖尚未缓存、网络下载慢 | 使用本地项目缓存并检查真实下载进度，没有把依赖失败算业务测试失败 |
| H2自动主键结果异常 | 通用插入取回多列生成值 | 明确只返回id，再运行集成测试 |
| 初版持久层偏离课程分层 | Controller含SQL，Store直接JDBC | 移至Service，Store委托实际MyBatis Mapper；BaseMapper与XML实际调用；重新审查通过 |
| 数量合并可能溢出 | 重复商品Integer相加可成负数 | Math.addExact和范围检查，回归测试覆盖 |
| 资金并发锁序相反 | 结账与收货锁用户及托管的顺序不同 | 共享托管行统一串行化资金事务，测试并发库存与幂等 |
| 自动等级可能覆盖手动设置 | 先读AUTO后无条件更新 | 最终UPDATE再次判断AUTO，增加并发回归 |
| 旧列表分页记录漏读 | 前端只读取第一页 | 读取全部页并断言101条记录，不遗漏旧订单和流水 |
| 原因弹框无法提交 | 有效输入错误返回了校验失败字符串 | 提取校验器，观察2项失败后修正；单元及真实浏览器回归通过 |
| 切页旧请求覆盖新内容 | 异步请求没有版本判断 | 商品及后台捕获路由与版本，清旧状态；迟到请求回归通过 |
| 管理员未创建 | 用户初始配置密码不足8位 | 用户自行修改后重启，确认管理员存在及真实登录成功 |
| 后端重启期间联调失败 | 旧Session失效，代理返回非JSON错误 | 服务稳定后重新获取验证码及Session，不复用失效身份 |
| 重复启动后端占用8080 | 既有项目进程仍监听 | 继续使用实际运行进程，避免启动第二个监听实例 |
| 中文PowerShell脚本解析失败 | Windows PowerShell5按ANSI读取UTF-8无BOM | 三个交付脚本改为UTF-8 BOM，重跑运行检查 |

每次修改后的真实测试证据见《联调与测试》。没有把初版问题隐藏成“从未失败”。
