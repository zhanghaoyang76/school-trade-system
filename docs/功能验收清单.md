# 功能验收清单

## 用途与状态

将课程原始要求及用户确认的规则映射到模块和验收步骤。依据为项目中的课程PPT、旧版Word、用户交接说明和本次需求确认记录。Word自动编号及费率表的完整提取仍需核对；本清单不虚构原文段落号。

当前为设计阶段：下表全部用例均未执行，不能作为测试通过记录。实施后逐项补充实际结果、命令或界面证据以及缺陷处理。

## 必选业务功能

| 编号 | 原始要求与确认规则 | 实现模块 | 验收方法 |
|---|---|---|---|
| 必01 | 随机图片验证码 | 账号与权限 | 验证图片可刷新，错误、失效验证码注册失败，正确验证码可提交 |
| 必02 | 普通注册资料与16位银行账号 | 账号与权限 | 姓名、手机号、邮箱、城市、性别等正确入库；非16位数字账号拒绝 |
| 必03 | 商家营业执照、身份证图片及资料 | 账号与权限 | 必填材料缺失不可提交，证件不可被其他普通用户读取 |
| 必04 | 注册审核后才能使用 | 注册审核 | 待审和拒绝账号不可正式登录，通过后可登录 |
| 必05 | 普通用户、商家、管理员权限 | 登录与权限 | 跨角色直接调用接口被拒绝；普通用户可作为个人卖家 |
| 必06 | 用户列表查看、修改、删除 | 后台管理 | 管理员可维护用户；已有业务记录的删除策略在设计确认后验证 |
| 必07 | 商品完整发布信息 | 商品与店铺 | 多图、名称、分类、原价、折扣、尺寸、使用说明、议价标识、数量、新旧程度可保存和展示 |
| 必08 | 商品审核 | 商品审核 | 未通过商品不进入可购买列表，通过后可购买 |
| 必09 | 发布、售出、下架列表 | 商品与店铺 | 卖家可查看对应列表并下架本人商品，不能操作他人商品 |
| 必10 | 店铺维度展示 | 商品与店铺 | 店铺名称、商品、库存、历史销量、评价可查看 |
| 必11 | 名称搜索跨商家商品 | 搜索 | 一个搜索可返回多个卖家符合名称条件的商品 |
| 必12 | 按价格、销量、好评率排序 | 搜索 | 用户切换规则后得到正确排序结果 |
| 必13 | 登录后使用购物车 | 购物车 | 未登录被拒绝，登录后可增加、调整数量、移除本人购物车商品 |
| 必14 | 跨商家购物车一键下单 | 订单 | 按卖家拆单，各订单记录各自交付约定，整次统一扣款 |
| 必15 | 下单锁定库存 | 订单与库存 | 并发购买不超卖；一件不足或无购买资格时，全部扣款库存回滚 |
| 必16 | 模拟钱包支付，不接真实支付 | 钱包 | 下单扣可用余额，余额不足下单失败，无真实支付网关 |
| 必17 | 时间地点约定、线下交付 | 订单 | 记录约定；卖家标记交付后开始7天计时 |
| 必18 | 交付前取消 | 订单 | 买卖任一方取消退还实际款和积分并恢复库存；重复取消不重复退款 |
| 必19 | 管理员指定用户充值 | 钱包与后台 | 正常充值增加余额并产生流水；非管理员不可充值 |
| 必20 | 中间账户托管 | 钱包与结算 | 下单未收货时卖家不可使用款项，托管金额与订单资金一致 |
| 必21 | 主动及7天自动确认收货 | 订单与结算 | 达到交付后7天时可自动处理；重复执行仅结算一次 |
| 必22 | 结算收入冻结24小时 | 钱包与结算 | 冻结收入不能消费；到期无售后才解冻 |
| 必23 | 个人免手续费，商家五档费率 | 结算 | 个人收费为零；商家按下单费率计算，两位小数；更改等级不追溯旧订单 |
| 必24 | 管理员指定及动态等级 | 评价与等级 | 自动模式按门槛更新；手动覆盖暂停自动；恢复后重新计算 |
| 必25 | 1元实付发1积分，100积分抵1元 | 积分 | 不足1元舍去；下单不能超余额或总额抵扣，新积分冻结24小时 |
| 必26 | 收货后24小时内申请退货 | 退货 | 期限内可申请，超时拒绝；按商品明细整项退 |
| 必27 | 卖家审核退货 | 退货 | 仅对应卖家能审核，审核通过立即退款，不等待交回 |
| 必28 | 在途退货、已退货展示 | 退货 | 审核通过在途，确认交回后已退货；仅交回后恢复库存 |
| 必29 | 退款、手续费及积分冲回 | 退货与结算 | 退对应实付款及原抵扣积分，取消奖励积分、冲回手续费，不重复退款 |
| 必30 | 商品文字与五星评价 | 评价 | 已购商品可评价，商品详情展示评价；未购买者不能冒评 |
| 必31 | 买家评价服务态度 | 评价 | 服务评价可保存并参与对应商家服务好评率 |
| 必32 | 卖家评价买家购买或退货行为 | 评价 | 对交易对方评价并展示买家好评率；具体评分规则待确认 |
| 必33 | 手续费管理相关业务展示 | 后台管理 | 管理员可查看等级费率、实收手续费、退货冲回和交易关联 |

## 已选可选功能

| 编号 | 功能 | 验收方法 |
|---|---|---|
| 选01 | 关闭店铺并全部下架 | 管理员关闭后不可新增发布及下单，已有订单与售后继续；重开后商品需重新审核 |
| 选02 | 商家拉黑及解除 | 被拉黑买家不可在本店下单，其他店不受影响；跨店结账包含本店时整体失败 |
| 选03 | 平台拉黑及解除 | 被拉黑买家全平台不可下单，已有订单及退货继续；解除后恢复购买资格 |
