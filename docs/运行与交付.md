# 运行与交付

## 当前运行入口

前端http://localhost:5173，后端http://localhost:8080；通过前端访问平台。管理员账号密码由用户自行填写在本地配置，文档不复述密码。

停止或重启后，按README中的两个启动脚本分别启动后端、前端。后端重启会使原Session失效，需要重新登录。

## 交付内容

完整前后端源码、17张表的MySQL脚本、配置样例、三个中文PowerShell脚本、自动化及浏览器验证脚本、中文阶段文档、接口契约、ER及系统图示、模块讲解、问题和主要提示词记录。

已选设计方向为Airbnb参考，正式页面使用真实接口及真实数据。六件联调演示商品和两类演示账号为实际验证生成，均明确标注示例；相关凭据仅本地.qa-local保留，未放到文档或版本库。

## 源码与远程仓库

本地开发分支development；用户指定远程仓库https://github.com/zhanghaoyang76/school-trade-system。推送前检查远程为空，并检查真实配置、上传目录、会话、依赖缓存及构建产物不纳入提交。最终推送和提交结果随后据真实命令更新，不能把配置remote等同于上传成功。

## 验收证据与讲解入口

从《联调与测试》查看各层真实验证，数据库查询结果保存在《数据库验证结果.txt》。从《模块讲解》按账户、商品、搜索、结账、钱包积分、售后、评价等级、后台及框架机制学习。

课程报告由用户自己撰写，系统问答应结合实际运行和源码说明；旧Word3.3标题仍须用户本人核对，不影响项目源码交付。
