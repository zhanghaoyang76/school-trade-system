# 设计预览访问排查

## 问题

用户反馈无法打开http://localhost:53147的设计预览。

## 实际检查与证据

1. 设计服务会话仍运行，能够输出整体架构及页面风格文件新增事件，不能仅因server-info文件存在就认定网络可访问。
2. 草图HTML存在且完整。先前受限环境HTTP检查返回套接字访问拒绝。
3. 在允许访问本机的检查环境请求http://127.0.0.1:53147，5秒后超时，确认访问链路存在问题；尚未证实是进程网络隔离、端口转发或其他原因。
4. 页面为自包含HTML，样式及交互脚本均在文件内部，没有远程资源或服务端请求依赖。

## 可用替代入口

将原草图复制到项目根目录的“页面风格预览.html”，便于使用系统浏览器直接打开。已校验复制前后的SHA256一致。

这个入口避免依赖本地HTTP端口。尚未观察用户实际打开结果，不声称网址已修复或浏览器验证已通过。

## 使用方法

在项目目录中双击“页面风格预览.html”，使用Edge或Chrome打开。三个方案分别为A清新校园、B活力集市、C简洁目录；选择结果在聊天中反馈。此文件仅用于设计评审，不是正式Vue前端。
