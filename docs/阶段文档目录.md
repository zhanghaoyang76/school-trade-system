# 阶段文档目录

## 文档规则

- 从需求确认至最终交付，每个阶段使用简体中文说明，文件名使用对应阶段名称。
- 每份文档记录阶段目标、输入依据、确认结果、实际操作、验证证据、问题和下一步。
- 后续实现阶段另外说明业务规则、前后端和数据库的数据流、框架机制、关键代码和答辩要点。
- 计划、提案、实际完成和实际验证必须明确区分。不得预填工时、测试通过结果和运行截图。
- 本目录及阶段文档为开发指导和真实过程记录，不作为用户实验报告正文代写。
- 阶段内持续更新文档；用户后续修改需求时记录修改及受影响内容。
